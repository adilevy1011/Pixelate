# Pixelate

Pixelate is an early-stage graphic and UI library written in C++, along with
its own programming language for designing small desktop UIs.

Windows is the original platform. An experimental Linux backend is also
available using GTK 3 and Cairo.

This project is currently under development.

See the [getting started guide](docs/README.md) and the [documentation index](docs/README.md) for usage instructions and language references.
